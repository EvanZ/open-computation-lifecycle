# OCLP JSON Schemas

These committed JSON Schema documents are published conformance artifacts for
the Open Computation Lifecycle Protocol. They are maintained alongside the
normative specification and cross-language fixtures in this repository.

The prose specification remains authoritative when a schema cannot express a
semantic rule. A protocol change must update the applicable specification,
schemas, fixtures, expected canonical JSON and digests, and independent
verifiers in one reviewable change.

SDKs consume and test against these files. No SDK generates them.
